|     | Подача заявок на депозиты с сайта и интернет-банка                                |              |
|     | Обработка заявок менеджерами через кол-центр и бэк-офис                                |              |
|     | SMS-подтверждения операций                                |              |
|     | Персонализированные ставки для клиентов                                |              |

|     | Идентификация новых клиентов в отделении                                |              |
| U   | Удобство использования (Usability) |              |
|     | Максимально удобный интерфейс для клиентов                                |              |
|     | Отклик в миллисекундах (сейчас справочники тормозят секунду+)                                |              |
|     | Соблюдение корпоративной системы дизайна                                |              |
|     | Привычные цвета и брендированные элементы                                |              |
| R   | Надёжность (Reliability)           |              |
|     | Доступность 99,9% (24/7)                                |              |
|     | Отказоустойчивость при сбоях ЦОД                               |              |
|     | Резервный ЦОД для переключения                                |              |
|     | Избежать прямой работы с перегруженной АБС          |
| P   | Производительность (Performance)   |              |
|     | Горизонтальное масштабирование интернет-банка                                |              |
|     | Распределение нагрузки между серверами и ЦОД                                |              |
|     |  АБС масштабируется только вертикально                               |              |
|     | Текущая проблема: база АБС уже перегружена                                |              |
| S   | Поддерживаемость (Supportability)  |              |
|     | Использовать существующие технологии банка (MS SQL, Oracle)                                |              |

|     |  Микросервисная архитектура для депозитов                               |              |
|     | Документация для расширения системы                                |              |
|     | Внутренняя экспертиза по новым технологиям                                |              |
| +R  | + Ограничения (Restrictions)       |              |
|     | Шифрование трафика на сайте и в интернет-банке                                |              |
|     | Защита чувствительной информации        |              |
|     | Команда интернет-банка говорит, что требования доступности пока невыполнимы |   |
|     | Текущая версия интернет-банка несовместима с Kafka                                |              |
